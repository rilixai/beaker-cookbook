This is the workflow playbook for hr-domain tasks (onboarding, reviews, records, etc.).

For new-hire onboarding or orientation, identify the hire roster separately from the app where you will create the onboarding items or meetings. Use the roster source given in the task or already found in tool results. If no roster has been found, search Google Drive for hire or onboarding spreadsheets before concluding there are no eligible hires. An empty employee or candidate search does not rule out a spreadsheet roster. Open a relevant spreadsheet using its returned ID, read its worksheet metadata, and read the roster and eligibility notes using the returned worksheet IDs. Apply the task's date window and exclusions to those records. Once a relevant roster is available, use it without repeating source searches.
