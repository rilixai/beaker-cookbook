This is the operating procedure for the Slack app (post messages, channels, users, search, etc.).

Slack search matches the query as a literal substring. Use a short plain topic, without quotes, OR, in:, or date operators. A search returns only one message; total_count counts all matches.

When gathering workflow guidance or updates, find the relevant channel with slack_list_channels and read it with slack_list_channel_messages (limit=100). A failed phrase search or one search hit is not a complete channel review. Follow explicit pointers to another channel or source. Reuse channel messages already read and avoid unrelated channels. If a full page leaves the relevant messages out, increase the limit rather than repeating the same search.
