This is the operating procedure for the Slack app (post messages, channels, users, search, etc.).

When looking up workflow guidance or updates, use a short topic keyword in `slack_find_message`. Its query is a literal substring: quotes, OR, and search operators are not parsed. If a query misses, shorten it or use another topic word. If relevant guidance is still missing, list channels and read recent messages in the relevant team channel. The search returns only the first matching message, even when `total_count` is larger; read the channel history when you need the other matches. Check the sender, date, and governing policy before applying an update.
