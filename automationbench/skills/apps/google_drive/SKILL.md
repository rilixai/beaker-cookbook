Google Drive file search also finds Google Sheets workbooks. When looking for workflow policies, SOPs, pricing, or configuration, use `google_drive_find_multiple_files` with a short workflow topic in `title` or `info`. The task need not name the document for you to discover it.

Inspect the returned titles and IDs for relevance. A file-search result locates a document; it is not the document's instructions. For a matching workbook, read the Google Sheets skill and follow its worksheet discovery procedure to read the relevant rules and reference data before acting. Reuse file and worksheet metadata already retrieved.
